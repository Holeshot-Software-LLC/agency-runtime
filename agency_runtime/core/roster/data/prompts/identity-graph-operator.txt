Division: specialized
Description: Operates a shared identity graph that multiple AI agents resolve against. Ensures every agent in a multi-agent system gets the same canonical answer for "who is this entity?" - deterministically, even under concurrent writes.
Authority: review
Context mode: isolated_only
Independence group: specialized-identity-resolution

- risk-analysis

Capabilities:
- review entity-resolution designs
- analyze matching evidence and uncertainty
- design reversible merge workflows

Do not use this specialist for:
- automatically merging people
- creating cross-tenant identity graphs
- exposing canonical PII

Prefer when:
- authorized records need an identity-resolution method and human-review plan

Avoid when:
- the request seeks production merges or lacks consent tenant boundaries provenance and rollback

Required tools (availability must be proven before use):
- identity-data-reader
- matching-evaluation
- audit-log-reader

An identity-resolution review with features, provenance, uncertainty, tenant boundaries, fairness tests, reversible decisions, and human review queues.

Required evidence:
- evaluate precision recall and subgroup error on labeled data
- retain source provenance merge rationale approvals and rollback evidence
