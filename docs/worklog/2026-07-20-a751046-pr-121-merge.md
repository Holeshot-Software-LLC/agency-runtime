# Worklog detail: Merge PR #121 performance gate isolation

## Purpose

Record the reviewed merge that removed wall-clock timing from the Python
compatibility matrix while retaining the dedicated performance gate.

## Approach

PR #121 separated compatibility correctness from shared-runner timing,
protected the workflow contract with a regression test, and reconciled AR-113
after the corrected hosted matrix passed.

## Challenges encountered

The defect appeared only when an explicitly performance-marked routing report
ran inside Ubuntu Python 3.12 under transient shared-runner load. The dedicated
uninstrumented performance job passed the same commit, identifying the duplicate
execution environment rather than a threshold or product regression.

## Decisions and alternatives

No threshold was relaxed. Performance tests remain required in their dedicated
job; compatibility cells run every non-performance correctness test across the
supported Python matrix.

## Verification

The final PR #121 candidate passed Ubuntu Python 3.10-3.14, Windows Python 3.10
and 3.14, exact coverage, unchanged routing/delegation performance, dashboard
UI coverage, portability, source audit, cross-platform artifact build, byte
parity and smoke, dependency review, and CodeQL. Strict tracker state reported
no open issues after merge.

None.
